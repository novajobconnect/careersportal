# University Prospectuses

Upload official university prospectus and course-information PDF files into this folder.

Suggested filenames:
- `TUT-2027-Prospectus.pdf`
- `UP-2027-Prospectus.pdf`
- `UJ-2027-Prospectus.pdf`

Before uploading, make sure each PDF is the latest official version and that you have permission to redistribute it. Keep the university's original source link available in the website where appropriate.
